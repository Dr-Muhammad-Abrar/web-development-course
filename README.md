### How to run the code

1. Download this repository: click the green **Code** button → **Download ZIP**, then unzip it.
2. Open the folder in [VS Code](https://code.visualstudio.com/download).
3. Install the **Live Server** extension, then right-click an `.html` file → **Open with Live Server**.

> **Embedded YouTube video not playing ("Error 153")?** Open the page with Live Server instead of double-clicking the file. The address must start with `http://`, not `file:///`.

### Practise with the validator

The file in `part-7-validator` contains **deliberate mistakes**. Paste it into [validator.w3.org](https://validator.w3.org) (*Validate by Direct Input*) and try to fix every error, then compare your answer with `full-project/Completeproject.html`.
